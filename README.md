# 🎮 Pokémon Rogue Dungeon (寶可夢地牢 Roguelike 冒險)

一個輕量、流暢且具備深度玩法的網頁版寶可夢 Roguelike 地牢冒險遊戲！選擇你的初始寶可夢，深入 15 層充滿未知的隨機地牢，挑戰野生寶可夢、強敵訓練家與傳說守護者！

---

## ✨ 遊戲特色 (Features)

- **8 隻初始寶可夢與異色模式 (Shiny Mode)**
  - 小火龍、傑尼龜、妙蛙種子、皮卡丘、伊布、利歐路、鬼斯、圓陸鯊。
  - 專屬種族值、特性（猛火、激流、茂盛、靜電等）與初始招式。
  - 支援一鍵切換異色形態 (Shiny)，享有專屬星芒與閃光特效！

- **隨機生成的程序化地牢 (Procedural Roguelike Map)**
  - 包含 15 層充滿挑戰的地下迷宮，每層有多條分支路線可供選擇：
    - ⚔️ **野外遭遇**：可將野生寶可夢 HP 壓低後投擲精靈球捕捉，擴充至 3 隻出戰隊伍。
    - 🥋 **訓練家對戰**：挑戰各路訓練家，贏取豐厚金幣與獎勵。
    - 🏕️ **避難休息營地**：溫泉修養（全隊 HP/PP 回復）、煮樹果咖哩（全隊最大 HP +15%）、招式特訓（招式威力 +10）。
    - 🏪 **地牢友誼商店**：購買各級精靈球、傷藥、文柚果與強效攜帶道具。
    - ❓ **神秘奇遇**：化石祭壇、吉利蛋之蛋、喵喵聚寶功老虎機與七彩泉水。
    - 👑 **守護者道館與傳說首領**：
      - 第 3 層：深灰道館館主 **小剛**
      - 第 6 層：華藍道館館主 **小霞**
      - 第 9 層：火箭隊首領 **坂木**
      - 第 12 層：神奧冠軍 **竹蘭**
      - 第 15 層：傳說寶可夢 **超夢**！

- **正統回合制戰鬥與屬性相剋 (Authentic Combat & Type Effectiveness)**
  - 速度決定出手順序、物攻/特攻 vs 防禦/特防傷害計算、STAB 同屬性加成、暴擊要害機制。
  - 即時屬性相剋效果預覽（絕佳 2x / 普通 1x / 微弱 0.5x / 無效 0x）。
  - 戰鬥中可隨時輪換寶可夢、使用背包藥品或投擲精靈球收服野怪。

- **形態進化與 Roguelike 三選一輪抽 (Evolution & Drafting)**
  - 達到特定等級自動觸發形態進化（如小火龍 ➔ 火恐龍 ➔ 噴火龍），數值全面暴漲！
  - 通關關卡後自選獎勵：強力招式、攜帶遺物（吃剩的東西、講究圍巾等）或全隊能力永久強化。

- **復古音效與視覺氛圍**
  - Web Audio API 8-bit/16-bit 復古音效合成器（打擊音、屬性剋制衝擊、升級號角、精靈球搖動與收服成功音效）。

## 🚀 本地開發與運行 (Local Development)

```bash
# 1. 安裝依賴
npm install

# 2. 啟動開發伺服器
npm run dev

# 3. 生產環境打包
npm run build
```
